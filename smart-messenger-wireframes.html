Smart Messenger — Website Wireframes

Desktop web app, WhatsApp Web–style layout: icon rail → list panel → main pane (+ optional right drawer). Grayscale only.

Onboarding→ Chats (Smart Inbox)→ Chat + AI Copilot→ Review & Send→ Add Reminder→ Reminders· Memory· Assistant· Settings
Navigation
5 rail items, always visible: Chats, Assistant, Reminders, Memory, Settings. Every screen is one click away.
Original vs AI
Solid borders = real messages and user data. Dashed border + ✦ = AI-generated suggestion.
Actions
Black filled = primary action. Outlined = secondary. Gray = cancel/dismiss.
